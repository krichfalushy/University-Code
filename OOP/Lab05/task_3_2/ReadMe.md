# task_3_2 — Будівельник рядка (StringBuilderEx)

Шаблон **Будівельник** для формування рядка:
- `append(...)` — додавання послідовності символів у кінець;
- `insert(pos, ...)` — вставка послідовності символів у вказану позицію;
- `build()` — отримання готового рядка (fluent interface).
Власний внутрішній буфер char[] з автоматичним розширенням.

Запуск: `javac src/*.java && java -Dstdout.encoding=UTF-8 -cp src Main`
