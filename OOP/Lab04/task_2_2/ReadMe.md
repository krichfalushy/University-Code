# task_2_2 — Парк муніципального транспорту (Abstract Factory)

Абстрактна фабрика виробника транспорту. Сімейство продуктів: Bus, Tram, Trolleybus.
Конкретні фабрики: Volvo, Skoda, Hyundai (значення з таблиць умови).
`TransportFleet` формує парк через фабрику й рахує повну вартість контракту
(закупка + експлуатація на N км). `Main` порівнює виробників і обирає найвигіднішого.

Запуск: `javac src/*.java && java -Dstdout.encoding=UTF-8 -cp src Main`
