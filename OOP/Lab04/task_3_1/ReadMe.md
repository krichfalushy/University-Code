# task_3_1 — Кав'ярня та виробники кавових машин (Abstract Factory)

Абстрактна фабрика виробника кавових машин. Сімейство продуктів:
CoffeeMachine + напої (Еспресо/Капучіно/Латте) — у кожного виробника свої
собівартість напоїв, вартість машини та обслуговування.
Конкретні фабрики: DeLonghi, Jura.
`CoffeeShop` рахує чистий прибуток за N днів (прибуток з напоїв − обслуговування − машина)
і день виходу в плюс. `Main` порівнює виробників.

Запуск: `javac src/*.java && java -Dstdout.encoding=UTF-8 -cp src Main`
