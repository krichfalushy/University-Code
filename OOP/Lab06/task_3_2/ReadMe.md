# task_3_2 — Прототип для Автомобіля (доповнення 4.3.1)

Шаблон **Прототип** для `Car` та компонентів (`Engine`, `Wheel`, `Transmission`).
- Усі класи `implements Cloneable`.
- `Car.clone()` виконує ГЛИБОКЕ клонування: окремо клонує кожну складову,
  тому клон не ділить компоненти з оригіналом.
- `Main` доводить незалежність: модифікація клона не змінює прототип,
  усі компоненти — різні об'єкти.

Запуск: `javac src/*.java && java -Dstdout.encoding=UTF-8 -cp src Main`
