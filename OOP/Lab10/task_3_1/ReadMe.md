# task_3_1 — Продуктовий супермаркет (Composite)

Рефакторинг із застосуванням шаблону **Компонувальник**.

- `Employee` — компонент (єдиний інтерфейс: payExpenses(), totalSalary()).
- `Salesperson`, `Manager` — листи (окремі працівники).
- `Department` — композит: очолюється менеджером, містить співробітників
  і/або інші відділи (рекурсія). Реалізує той самий інтерфейс.

Структура: супермаркет (директор-менеджер) -> 3 відділи (м'ясний, молочний,
кондитерський), кожен з менеджером і трьома продавцями. Виплата зарплати всім —
одним викликом payExpenses() на кореневому об'єкті; сумарний фонд — totalSalary().

Запуск: `javac src/*.java && java -Dstdout.encoding=UTF-8 -cp src ExpensesClient`
