# task_3_1 — Image Gallery (Proxy)

Реалізація шаблону **Замісник** (віртуальний proxy) для відкладеного
завантаження зображень.

- `DisplayObject` — спільний інтерфейс (display()).
- `ImageFile` — реальний об'єкт; завантажує файл з диску в конструкторі (load()).
- `ImageProxy` — замісник: зберігає лише шлях і НЕ читає файл, доки display()
  не викликано вперше. Реальний ImageFile (і завантаження) створюється "ліниво",
  а повторні виклики display() не перезавантажують файл.

Завдяки цьому при створенні галереї жодне зображення не зчитується з носія —
завантаження відбувається лише безпосередньо перед виведенням на екран.

Запуск (GUI через Swing):
`javac src/*.java && java -cp src ImageGallery`
(шлях до resources/ відносний; за потреби заміни на абсолютний у ImageGallery)
