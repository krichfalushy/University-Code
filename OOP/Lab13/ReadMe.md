# task_3_1 — Автоконструктор (Flyweight)

Реалізація шаблону **Легковаговик** для повторного використання деталей авто.

- `Engine`, `Wheel` — легковаговики (незмінні спільні об'єкти, внутрішній стан).
- `EngineFactory`, `WheelFactory` — кешують створені деталі за ключем і повертають
  той самий екземпляр для однакових параметрів.
- `Car` — контекст: зберігає унікальний (зовнішній) стан (тип, колір) і посилається
  на спільні Engine/Wheel.
- `CarBuilder` бере деталі з фабрик-легковаговиків.
- `CarSimulator` створює N авто та показує економію: скільки реально унікальних
  Engine/Wheel замість окремого об'єкта на кожне авто.

Запуск: `javac src/*.java && java -Dstdout.encoding=UTF-8 -cp src CarSimulator`
