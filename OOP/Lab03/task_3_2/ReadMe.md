# task_3_2 — Ієрархія рівнянь

- `Equation` — лінійне b*x + c = 0 (базовий клас, метод `solve()`).
- `QuadraticEquation` — a*x^2 + b*x + c = 0.
- `BiQuadraticEquation` — a*x^4 + b*x^2 + c = 0 (заміна t = x^2).
- `EquationFactory` — створює рівняння за кількістю коефіцієнтів (2/3/5).
- `Main` — читає input01..03.txt і рахує: скільки рівнянь з 0/1/2/3/4/∞ розв'язками,
  а також рівняння з найменшим і найбільшим коренем серед тих, що мають рівно один розв'язок.

Запуск: `javac src/*.java && java -Dstdout.encoding=UTF-8 -cp src Main`
(вхідні файли input0*.txt лежать поруч зі скомпільованими класами або в робочій теці)
